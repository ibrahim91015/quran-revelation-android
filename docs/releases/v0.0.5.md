# Quran Revelation v0.0.5

This update refines sajdah alerts and translation picture-in-picture on Android 16. Install the signed APK over v0.0.4 to retain downloads and preferences. It continues to install alongside the original Quran.com app.

## Sajdah timing and vibration

- The media chime starts at the beginning of the sajdah pause. The timed interval starts when the sound starts, so cold sample loading cannot consume the pause. The existing choices remain Off, 2 seconds (default), 5 seconds, Until I resume, and Custom 0–60 seconds.
- Completion notifications arrive at that same boundary. The alert channel now vibrates, remains high importance, and has no notification sound; the separate chime continues to use Android's media volume, including in vibrate mode.
- **Notify when a sajdah ayah starts** is a new setting, off by default. When enabled, the notification first says **A sajdah ayah is playing**. It changes to **A sajdah ayah has played** at completion without a second vibration. The chime remains at completion, at the beginning of the pause.
- The alert clears after the next recited ayah finishes, including Al-‘Alaq 96:19 → Al-Qalam 68:1 in revelation order. Explicit stop/seek/new-session actions clear it. Manually pausing or browsing elsewhere still cancels automatic resume.
- Android 8+ uses a new notification channel to apply vibration when upgrading from the previously non-vibrating channel. Notification permission, channel settings, Do Not Disturb and system notification cooldown can affect heads-up alerts and vibration. Muted media can mute the chime.

## PiP reading comfort

- The screen stays awake while the translation PiP window is visible. Closing it releases that request and keeps audio playing. The power button still works normally.
- **Translation PiP appearance** now includes No margins, Compact (4 dp), Balanced (8 dp, default), and Relaxed (16 dp) presets, plus an adjustable 0–24 dp edge-margin slider.
- **No margins** top-aligns the translation and intentionally permits approximately half a character to crop at each horizontal edge. Other margin choices preserve full letters. The whole translation remains in the layout without ellipsis; the reference keeps a separate row to avoid overlapping the translation.
- Choose a short reference such as **2:113**, or **Full surah name and ayah**, using the same localized label as the live audio notification.
- Place the reference in any of the four physical corners: top left, top right, bottom left, bottom right. Bottom right remains the default.
- Centered/justified alignment, preferred maximum font size (14–48 sp), automatic long-ayah fitting, app colors/dark mode and translation fonts are retained. Settings apply live; Save, Cancel and Reset include the new controls. The enlarged settings dialog scrolls on small screens.

## Preserved features and upstream base

The 89-reciter catalog, MP3/Opus alternatives, gapless/downloaded/streamed playback, revelation queue, picker behavior, persistent paused audio notification, independent package/signature and six built-in chimes are retained. This release keeps the 17 upstream commits merged in v0.0.4 through `6a999e5dc657d880a65b19c5c458843ffc446d6d`; see the [upstream integration review](../upstream/2026-10-31.md).

## Verification

The release includes a validation report, checksums and test evidence. Device automation covers real Media3 playback on Android 16, completion/start notifications, chime playback during the pause, vibration channel configuration, revelation transitions, no skipped short-surah tails, live PiP appearance changes, screen timeout and audio continuing after dismissal. Native-font tests exercise long English/Arabic translations, edge margins, all four reference corners and complete text fitting. The signed release is also checked as an upgrade beside the original app.

Emulator tests cannot establish how loud the chime or strong the vibration feels on a physical phone. Android controls PiP size/controls and vendor power restrictions. Very long translations shrink to fit; enlarge PiP for readability. Account sync still needs OAuth registration for this independently signed fork, and Android's private storage still prevents silently accessing another app's downloads.
