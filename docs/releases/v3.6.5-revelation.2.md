# Quran Revelation for Android — 3.6.5-revelation.2

This update focuses on background listening, Android 16 notifications, touch handling, and a more consistent Material 3 interface. It updates the existing independent fork; install it over revelation.1 to keep your settings and downloads. The original Quran for Android remains separate.

## Changes

- Returning to the surah picker keeps audio running. A now-playing card shows the reciter and current verse, with pause/resume and a route back to the reader.
- Paused playback retains its ongoing media notification. Notification and system media-card taps open the current ayah in the session's selected surah order. Reciter, surah/ayah, order, playback speed, and paused position are supplied to the media session.
- Gapless surahs wait for the audio player's file-completion event before advancing. An early timing-database end marker no longer cuts off the recording's tail. File completion also handles a delayed last-verse tracking update.
- Mushaf margins open the reading controls instead of selecting the nearest verse. Coordinate conversion accounts for scaled images and display padding.
- Adjacent pages keep their slide; distant revelation-order jumps use a short fade instead of sweeping through unrelated pages. Disabled system animations are respected.
- Blue, Emerald, Violet, and Amber accent choices are available under Display Settings, with light/dark palettes for native and Compose controls. Native activity themes and the new playback card use Material 3 components.
- An optional gentle sajdah tone sounds after the marked verse finishes, using media volume. Settings can disable it. The fifteen markers follow [Tanzil's Quran metadata](https://tanzil.net/docs/Quran_Metadata).
- Advanced Settings no longer crashes when the optimized release constructs the bookmark JSON adapter. The release shrinker now preserves the reflected bookmark-color enum fields, including `TEAL`.
- Advanced Settings detects the original installation and offers **Import audio and translations** for an accessible copied Quran folder. Copies are validated, incomplete copies stay temporary, and existing downloads are kept.
- English and Arabic labels cover the added settings and playback controls.

## Importing existing downloads

Choose a folder containing `audio/` and `databases/`, preserving the original reciter paths. Open Translations afterward to review imported texts; a catalogue refresh may need Internet. The importer copies complete MP3/Opus files and compatible translation/timing databases into this app's storage. It leaves the selected source unchanged and keeps existing destination files.

Android 11 and later prevent reading another app's private storage or selecting its `Android/data` directory. Detection of the original app does not grant access to its downloads. Use an accessible export or copy if one is available; otherwise download the assets in this app. Bookmarks still use their separate import/export option. See [Android's storage access documentation](https://developer.android.com/training/data-storage/shared/documents-files#document-tree-access-restrictions).
