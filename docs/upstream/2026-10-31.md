- **Bookmarks and migrations:** reviewed page-provider identities, reference-page fallback, page-range clamping, per-mushaf bookmark storage and import normalization. Upstream regression/migration coverage runs together with the fork's tests.
- **Account sync:** reviewed foreground observer ownership, configured/authenticated guards, cancellation propagation, session-ended state and sign-out handling. Account sync still needs an OAuth registration for this independently signed clone; local features require no account.
- **UI and lifecycle:** upstream foreground sync runs at process scope. It does not replace the fork's activity routing, paused-session protection, stored tab order/offsets or now-playing card.
- **Recitation:** upstream's changes do not touch the fork's `RevelationOrder`, audio queue, MP3/Opus selection, or 3.6.4 reference reciter catalog. The Madani page-provider merge adds its mushaf identity without dropping its reciters.
- **Build:** accepted KSP, Metro, mobile-sync, Error Prone, Google Auth/Speech and account UI dependencies. Both debug/device-test builds and the signed, shrunk release are verified.
